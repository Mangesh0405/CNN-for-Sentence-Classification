# CNN-for-Sentence-Classification
• Implemented a CNN-based sentence classification model using pre-trained Word2Vec embeddings, multiple
convolutional filter widths and max-over-time pooling for extracting meaningful phrase features for NLP use
• Developed an end-to-end NLP pipeline with tokenization, embedding generation, convolutional feature
extraction, dropout regularization, and softmax prediction for sentiment and document classification ML tasks
• Experimented with static and fine-tuned word embeddings to study task-specific representation learning for sen-
tence text classification, evaluating their impact across multiple sentiment and benchmark datasets and tasks
